# FiOzil — Fabricación Digital

Sitio web estático de FiOzil, listo para publicar en **GitHub Pages**.

## Publicar en GitHub Pages

1. Crea un repositorio en GitHub y sube todos los archivos de esta carpeta (incluido `index.html` en la raíz).
2. En el repositorio ve a **Settings → Pages**.
3. En **Source** elige **Deploy from a branch**.
4. Branch: `main` (o `master`) y carpeta `/ (root)`.
5. Guarda. En unos minutos el sitio estará en:

- Proyecto: `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`
- Si el repo se llama `TU-USUARIO.github.io`, el sitio queda en `https://TU-USUARIO.github.io/`

No uses rutas absolutas tipo `/css/styles.css`; este proyecto ya usa rutas relativas para que funcione en Pages de proyecto.

## Estructura

- `index.html` — inicio (diseño de referencia)
- `productos.html` — catálogo
- `personalizacion.html` — cotización por WhatsApp
- `nosotros.html` — sobre FiOzil
- `contacto.html` — datos y formulario
- `detalle.html` — ficha de producto
- `css/`, `js/`, `images/`
